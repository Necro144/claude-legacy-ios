## What's new in 1.1.0

- Pure black OLED theme, dark only.
- Native three-tab layout: Claude, Chat and Settings. The Claude tab is full screen with no browser bar, and pull-down refresh.
- Chat tab rebuilt: start screen, growing input box, code blocks with a copy button, and the conversation is saved on the phone.
- Settings: pick the Claude version (Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5 or a custom model id), system prompt, creativity, reply length and API key.
- New About section: version number and "Made by Necro".
- New app icon.
- Needs iOS 16 or later (was 15).

## Install

Download `ClaudeLegacy.ipa` below and install it with TrollStore, AltStore or Sideloadly. It is unsigned.
