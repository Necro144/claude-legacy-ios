## What's new in 1.3.0

A sturdier Claude tab, built from what was learned fixing the Suno app.

- **Sign-in and other popup windows now work.** If a page opens a window (for example a sign-in), the app opens a real window with a Done button instead of loading a blank page into the main screen. That blank-page behaviour is what turned the Suno app black after logging in, and Claude's sign-in uses the same kind of windows.
- **Native alerts.** Messages and confirmations from the website show as iPhone alerts.
- **Downloads** open the iPhone share sheet so you can save them to Files.
- **Links** like mail and phone open in their own apps.
- **Microphone** access asks permission once.
- **No silent black screens.** If a page comes up empty, a panel offers Reload and Copy details, and the Page errors list in Settings records what happened.
- **More compatibility fixes** for newer web features that iOS 16 lacks.
- Tested on a real iOS 16.4 simulator (the app opens, the sign-in popup flow works, alerts and the blank-page panel show). Whether Claude Code's page now works on your phone is still unconfirmed: if it stays black, copy the list from Settings > Page errors and send it.
