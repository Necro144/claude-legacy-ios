## What's new in 1.1.1

- Fix for the black screen when opening Claude Code from the sidebar. The Claude tab now identifies itself as Safari 16.4, and fills in newer web features that iOS 16 lacks (Promise.withResolvers, Object.groupBy, Set methods, requestIdleCallback and others) that the page may rely on. I could not test this on the Claude Code page itself.
- New Settings > Diagnostics > Page errors, which lists the errors the Claude tab reports. If Claude Code is still black, open it, then copy the list from there.
