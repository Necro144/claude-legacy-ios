## What's new in 1.3.1

Downloads from the Claude tab work: files you save from Claude (code files, documents, exports) now open the iPhone share sheet, where you can tap **Save to Files**.

- **Why it could fail.** Some sites build a file in memory, click a hidden download link and discard the file a split second later. A normal browser copes with that, but the iPhone's download system starts too late and finds the file gone, so nothing happens. The app now grabs the file the instant the link is clicked, saves it, and shows the share sheet.
- Links straight to an audio or zip file are downloaded instead of replacing the whole screen.
- Settings > Page errors now also records downloads (started, saved, size).
- Tested on a real iOS 16.4 simulator with a page that copies that pattern: the 2.5 MB test file was saved in full and the share sheet appeared, and normal and cross-site links worked too. I could not press Claude's own download buttons (they need a logged-in account) and have not tried it on a physical iPhone.
