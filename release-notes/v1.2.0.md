## What's new in 1.2.0

- **"Device software is out of date" notice.** The Claude tab now presents itself as a newer Safari (Compatibility mode, on by default in Settings) and hides that notice if the site still shows it. Close and reopen the app after changing the switch.
- **Claude Code black screen.** Still not confirmed fixed, because I can't run that page here. The app now records what happens when a page loads (HTTP errors, JavaScript errors, and whether the page ended up empty). Open Settings > Claude tab > Page errors after a black screen and copy the list.
- **Blacker everywhere.** The window behind every screen is pure black, and the Claude tab asks the site to use black instead of dark grey. The site's colours can change, so some greys may remain.
- **Chat rebuilt.** Many saved chats with a history list (swipe to delete), formatted replies (headings, bullet and numbered lists, quotes, code blocks with copy), regenerate (press and hold a reply), and haptic feedback.
- Settings: Delete all chats, Compatibility mode, Page errors.
