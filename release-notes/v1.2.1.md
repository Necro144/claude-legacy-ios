## What's new in 1.2.1

- **Use two accounts.** Every release now includes a second copy of the app, `ClaudeLegacy-2.ipa`. It installs as a separate app called **Claude 2** with a dark icon, and keeps its own login, chats, API key and settings. Sign in to one account in each copy and switch by opening the other app.
- No other changes.

## Install

Download `ClaudeLegacy.ipa` for the first account and `ClaudeLegacy-2.ipa` for the second, and install each with TrollStore, AltStore or Sideloadly. They are unsigned. With AltStore or Sideloadly a free Apple ID allows only a few apps at once, so TrollStore is easier.
