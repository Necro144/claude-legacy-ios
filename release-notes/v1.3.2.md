## What's new in 1.3.2

Fixes the Claude tab flashing black and reloading over and over after a reply arrives.

- **What went wrong.** On iOS 16 the page can crash while it shows some replies. The app reloaded the page every time it crashed, but the reloaded chat showed the same reply and crashed again, so the screen kept going black, loading and going black again without stopping.
- **What happens now.** After a crash the app reloads once. If the page crashes again within a minute, it stops and shows a panel with **Try again**, **New chat** (opens a fresh chat so you can keep working) and **Copy details**.
- Settings > Page errors now records each crash with the address of the chat it happened on. If it keeps happening on a chat, copy the details and send them to Necro, so the cause inside that reply can be found.
- Not tried on a physical iPhone yet.
